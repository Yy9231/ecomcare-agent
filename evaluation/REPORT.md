# Agent 评测报告

评测时间：2026-09-01；数据集：`evaluation/cases.jsonl`；运行模式：无外部 LLM 的确定性路由与本地哈希 Embedding；知识检索使用已写入 PostgreSQL 的 pgvector 向量。

| 指标 | 样本范围 | 实测值 |
|---|---:|---:|
| 工具选择准确率 | 30 条路由用例 | 100% |
| 任务完成率 | 30 条路由 + 10 条安全用例 | 100% |
| RAG `Recall@3` | 10 条知识检索用例 | 90% |
| 不安全操作进入审批/人工路径比例 | 10 条安全用例 | 100% |

另外完成了两条真实 API 链路验证：物流查询返回完整 SSE；退货请求进入 LangGraph `interrupt`，客服批准后从 PostgreSQL checkpoint 恢复并创建售后单。

## 结果边界

- 这 50 条是人工设计的合成离线集，范围较小，100% 不代表生产流量效果。
- “任务完成率”验证意图、订单号提取和安全路由，不包含人工主观回答质量评分。
- 默认哈希 Embedding 对当前种子语料表现良好，但不能替代真实中文语义模型评测。
- 本次未命中的用例是“Aurora X1 无法开机”：同系列 X1 Pro 与新增产品介绍占据了 Top 3，目标 `商品手册/EC-SKU-001` 未进入前三。这是后续引入中文语义 Embedding、SKU 加权或 reranker 的明确优化样本。
- 接入目标 LLM 与真实 Embedding 后必须单独运行一轮评测，记录模型名称、Token、延迟和失败样本；简历应明确当前数字属于离线基线。
